WRITING STYLE RULES:
- Always use present tense when referencing authors: "Smith argues", "Jones demonstrates", "Lee shows"
- Use temporal connectors to show progression: "More recently,", "Modern approaches,", "Building on this,"
- Use connective phrasing between paragraphs so ideas flow naturally into one another
- Every statement of fact must be precise and specific — avoid vague language like "some researchers believe" or "it has been shown"
- Never use filler phrases: avoid "It is important to note", "It is worth mentioning", "As mentioned above"
- Vary sentence length deliberately: mix short punchy sentences with longer explanatory ones
- Avoid starting consecutive sentences with the same word
